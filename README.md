# 🤖 Jarvis Omarchy

Локальный голосовой и текстовый AI-ассистент (J.A.R.V.I.S.) для Omarchy / Arch Linux. 
Работает полностью офлайн на вашей видеокарте, не требует VPN и облачных API.

## ✨ Возможности
- **Два режима:** Общение (чат) и выполнение shell-команд.
- **Локальность:** Работает на Ollama (Qwen3 8B).
- **Интерфейс:** Использует `aichat` для удобного терминального чата.
- **Безопасность:** Сгенерированные команды требуют подтверждения перед запуском.
